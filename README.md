# 家屋調査ナビ

家屋調査（退院前の住宅訪問）で使う、間取り図と報告書の作成ツールです。ブラウザで開いて使います。

- 壁・建具・設備・家具・福祉用具を置いて、手すりや段差、寸法を書き込めます
- スキャンアプリで書き出した間取り図の画像を下絵にして、縮尺を合わせられます
- 描いた図は、使っている端末の中にだけ保存されます（このページやGitHubには送られません）
- 場所ごとの評価・寸法・写真から、A4 2枚の報告書（PowerPoint・PDF）を作れます
- iPad（指・Apple Pencil）でも使えます

開く: https://reha-tools.github.io/madori-tool/
